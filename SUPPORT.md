# Support

ATO Bot is community-supported open-source software. Before opening an issue:

1. Review the README, deployment documentation, and feature-status registry.
2. Confirm the issue occurs on a supported release with experimental features disabled.
3. Remove credentials, assessment evidence, customer names, hostnames, and internal addresses from logs.

Use GitHub Discussions for usage questions and GitHub Issues for reproducible defects after those features are enabled. Security vulnerabilities must follow `SECURITY.md` and must not be posted publicly.

Experimental and beta capabilities are provided for evaluation and do not carry the same compatibility or support guarantees as supported features.
